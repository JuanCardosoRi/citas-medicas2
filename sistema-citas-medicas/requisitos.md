# Requisitos del sistema

## Requisitos funcionales
| ID | Requisito | Prioridad |
|---|---|---|
| RF-01 | El sistema debe permitir al paciente registrarse e iniciar sesión con correo y contraseña. | Alta |
| RF-02 | El sistema debe permitir buscar médicos por especialidad y ver su disponibilidad. | Alta |
| RF-03 | El sistema debe permitir al paciente agendar una cita en un horario disponible. | Alta |
| RF-04 | El sistema debe permitir reprogramar o cancelar una cita con al menos 24 horas de anticipación. | Media |
| RF-05 | El sistema debe mostrar al médico su agenda diaria de citas. | Media |

## Requisitos no funcionales
| ID | Requisito |
|---|---|
| RNF-01 | El sistema debe responder en menos de 3 segundos en operaciones comunes. |
| RNF-02 | Los datos personales y clínicos deben protegerse según la normativa de protección de datos vigente. |
| RNF-03 | La interfaz debe poder usarse desde computador y celular. |
